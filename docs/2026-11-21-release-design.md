# 源码与发布管理方案

用户指定 Codex outputs 内的「骨样标注优化工具」为唯一源码目录；该目录的 Git 仓库是维护入口。E 盘已安装软件只作为运行副本，修复和扩展都在源码目录完成，再发布安装。

## 版本与验证

保留共享处理内核和 GUI/CLI 入口，增加固定依赖、无私人数据的 GUI 自动测试、核心测试和 Labelme 兼容检查。每次提交在 Windows CI 执行核心与 GUI 测试。发布构建前执行相同测试，生成版本清单、源码提交号和 SHA256。初次发布版本 1.1.0。

## 独立打包

使用干净 Python 3.11 环境和 PyInstaller onedir，包含 Qt/OpenCV/NumPy/Pillow；生成 GUI exe 和 CLI exe，压缩整个目录得到便携版。Inno Setup 构建安装程序，显示安装路径选择页，支持桌面快捷方式、升级及卸载。软件不嵌入 Labelme 和模型；用户可以选择其本机 Labelme 启动程序。设置保存在当前用户 QSettings 中，安装升级不清空设置。

## 可移植性

移除源文件中机器专用的数据路径，第一次从选择的标注目录推导输出目录，记住选择。已存在的本机输出和照片设置继续使用。启动外部 Labelme 的命令区分源码模式和 frozen 模式，禁止把打包软件自己当 Python 启动，缺少 Labelme 时提供选择入口。

## GitHub

用户已授权公开仓库。发布源代码、说明、测试和脚本；忽略实验图片、标注 JSON、本机验收记录、快捷方式、依赖二进制和构建产物。首次推送后核对远端提交及自动测试结果。未指定开源许可证，暂不擅自为用户代码授予额外许可。
