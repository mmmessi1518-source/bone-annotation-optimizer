# 骨样标注优化工具 1.0

用户已批准中文本地桌面工具和共享处理内核。输入原始 Labelme JSON，保留原稿，单文件/批量导出可继续编辑的 Polygon JSON；不依赖在线 AI 或 GPU。

## 处理合同
- 接受 polygon、rectangle、circle、oriented_rectangle、旧版 mask；拒绝未知标签和线/点等无确定区域的形状。
- specimen 定义样品范围；其外全部 background。内部 ignore 优先。
- 自动判断单一组织类别并推导补集；两类齐全时冲突及空隙为 ignore。不猜测组织医学含义。
- 小区域使用原图分辨率、8 连通、面积 <= 阈值，两类一视同仁；0 关闭。默认 100 可调。每次从导入基线计算，不累计侵蚀。
- 重新导入已优化 JSON 时读取全部现有图形，包括人工修改过的生成图形。已导出的 ignore 不凭空恢复。
- 手动选择单类相减但文件含另一类时，先逐像素验证现有另一类与补集完全一致；一致才继续，不一致保留报错，避免覆盖人工修改。
- 内部使用 NumPy/OpenCV 分类数组。出口采用无洞轮廓分区，全部 polygon。先回读逐类别校验完全相同，再原子保存。存在孔洞的区域拆成同标签多个多边形，可能显示分区接缝，但不生成 Mask 外接矩形。
- 不做会改变有效细节的轮廓平滑。只有回读像素完全不变的简化可接受。细长且连接主区域的缝隙不会被小独立区域阈值删除。
- 图片引用唯一匹配后修复；歧义、损坏、未知标注拒绝导出。输出与原稿不得同路径，不覆盖已有文件，自动递增输出文件名。

## 模块
`annotation_io` 文件/图片/原子保存；`core` 分类、连通区域缓存；`vectorize` 可编辑轮廓与逐像素验证；`service` 同步导出服务；`gui` Qt 工作线程和缩放预览；`cli` 批处理调用。UI 线程不做图片运算，批次串行避免大图并发占满内存。
