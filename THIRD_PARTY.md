# Third-party runtime components

The independent application bundles Python, PyQt5/Qt5, PyQt5-sip, NumPy,
Pillow and OpenCV headless. Their copyright notices and licenses remain those
of their respective authors. Distribution metadata/license files are collected
by the packaging spec into the runtime folder. Review the corresponding package
license files when redistributing binaries; this repository does not grant
additional rights in those dependencies.

PyInstaller is a build tool and Inno Setup is the installer compiler. Labelme is
an external application and is not bundled. No experiment images, annotations,
AI models or user credentials are included in the source or build inputs.
